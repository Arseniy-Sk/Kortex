# Kortex — portfolio assets

Mechanical keyboard studio for QMK/VIA boards. Windows desktop app,
WPF on .NET 9, no third-party dependencies.

| File | What it shows |
|---|---|
| `01-overview.png` | Welcome screen: positioning, feature cards, quick start |
| `02-key-tester.png` | Switch tester with wear heatmap, chatter diagnostics and event log |
| `03-board-keymap.png` | Firmware keymap editor: layers, matrix mapping, QMK keycode picker |
| `04-remapping.png` | Windows-level remapping for boards without QMK |
| `05-macros.png` | Macro editor with automation steps and firmware write-back |
| `06-device.png` | Detected boards, capabilities, RGB lighting and service commands |
| `07-profiles.png` | Profiles, board build variants, tester settings |
| `08-hero.png` | Title render for the portfolio header |
| `09-palette.png` | Colour system |
| `10-features.png` | Feature sheet |
| `logo.png` | Brand mark, 512 px, transparent background |

Screenshots are captured at 2x pixel density from the running application.
The connected board in the shots is the built-in demo device, so the data is real
application output rather than a mock-up.
