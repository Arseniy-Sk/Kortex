# Kortex — студия механических клавиатур

Одна программа вместо VIA, Vial и тестера клавиш. Kortex сам находит подключённую клавиатуру,
читает её прошивку по протоколу VIA и даёт править раскладку, слои и макросы. Для плат KBDfans,
включая **KBD8X MKIII**, это полная замена VIA и Vial; для клавиатур без QMK работает программный
слой поверх Windows.

WPF, .NET 9, без внешних зависимостей. Интерфейс на русском и английском.

| | |
|---|---|
| Название | **Kortex** |
| Тэглайн | Студия механических клавиатур / Mechanical keyboard studio |
| Знак | Монограмма **K** в скруглённом квадрате, градиент violet → cyan |
| Палитра | `#7C6BF7` акцент · `#35D6E8` данные и железо · `#3DDC97` норма · `#F5B24A` внимание · `#FF6B6B` ошибка |

Фирменные механики: **Kortex Pulse** — волна, расходящаяся от нажатой клавиши; **Heatmap** —
тепловая карта износа платы; **Switch Health** — детектор дребезга; **Dual Engine** — прошивочный
и программный режимы с одинаковой логикой настройки; **Matrix Learn** — автоматическое
сопоставление физических клавиш с матрицей платы.

## Разделы

### Обзор
Приветственный экран с описанием, возможностями и шагами быстрого старта. Показ при запуске
отключается переключателем.

### Тест клавиш
Схема платы подсвечивает нажатия в реальном времени, проверенные клавиши остаются отмеченными.
Счётчик нажатий по каждой клавише, прогресс, **детектор дребезга контакта** (повтор раньше порога —
клавиша краснеет и попадает в диагностику), максимум одновременных нажатий (NKRO), журнал событий
с VK- и скан-кодами, тепловая карта износа, блокировка Win / Alt+Tab на время теста.

### Раскладка платы
Чтение слоёв прямо из прошивки, правка клавиш с немедленной записью в память платы, переключение
слоёв, сброс раскладки, каталог кодов QMK с поиском. Сохранение и загрузка раскладки в формате
файлов VIA — один и тот же файл читают и Kortex, и VIA. Изменения остаются в плате после закрытия Kortex.

### Переназначение
Программный слой поверх Windows для клавиатур без QMK: другая клавиша, макрос, вставка текста
или отключение клавиши. Работает во всех приложениях, пока Kortex запущен.

### Макросы
Запись последовательностей с реальными паузами, ручная правка шагов, повторы, скорость,
пробное проигрывание, привязка к любой клавише.

Одиннадцать типов шагов:

| Шаг | Что делает |
|---|---|
| Нажать · Зажать · Отпустить | клавиша целиком или удержание модификатора |
| Пауза | задержка в миллисекундах |
| Текст | печать произвольной строки, раскладка не важна |
| **Запустить** | программа, файл, папка или ссылка — с аргументами, как двойной щелчок в проводнике |
| **Клик** | левая, правая или средняя кнопка мыши |
| **Курсор** | перемещение абсолютно в точку экрана или относительно текущего места |
| **Прокрутка** | колесо мыши на заданное число щелчков |
| **В буфер** | положить текст в буфер обмена |
| **Дата/время** | подставить текущую дату по своему формату |

Макросы из клавиш, пауз и латинского текста записываются прямо в память платы кнопкой
«Записать в плату» и работают без запущенного Kortex. Кнопка «Прочитать с платы» забирает
макросы, уже лежащие в прошивке. Шаги с запуском программ, мышью и буфером обмена прошивка
выполнить не может — они остаются в программном режиме, и Kortex прямо говорит, что пропустил.

В новом профиле сразу лежат пять готовых заготовок — `Alt + Tab`, `Win + D`, `Ctrl+C → Ctrl+V`,
`Ctrl+Z ×3` и текстовая подпись. Кнопка «Стандартные» возвращает их в любой момент, не трогая
то, что вы создали сами.

### Устройство
Список найденных клавиатур с моделью, производителем, VID/PID, форм-фактором, версией протокола VIA,
числом слоёв, размером матрицы и слотами макросов. Список HID-интерфейсов устройства.
Управление подсветкой: яркость, эффект, скорость, оттенок и насыщенность с сохранением в плату.
Обслуживание: сброс памяти платы к заводским настройкам и перевод в режим прошивки.
Демо-плата позволяет изучить интерфейс без железа.

### Профили
Несколько профилей с отдельными переназначениями, макросами и вариантом сборки платы
(ISO Enter, Split Backspace, Stepped Caps Lock, Split Right Shift, 7u Spacebar).
Импорт и экспорт в JSON, выбор языка, параметры теста.

## Как устроено определение платы

1. Перечисляются все HID-интерфейсы системы (`setupapi` + `hid.dll`), устройства группируются
   по VID/PID.
2. Модель и производитель берутся из USB-дескриптора самого устройства — поэтому распознаётся
   любая клавиатура, а не только записанные в каталог.
3. Каталог уточняет форм-фактор и размер матрицы для известных семейств; платы KBDfans и всё,
   что сообщает о себе как `KBD8X`, получают полный профиль TKL.
4. Интерфейс сырых отчётов (usage page `0xFF60`, usage `0x61`) опрашивается командой
   `id_get_protocol_version`. Ответила — плата VIA-совместима, доступен раздел раскладки.
5. Найденная VIA-плата подключается автоматически.

### Сопоставление с матрицей

VIA берёт размеры матрицы и позиции клавиш из файла описания платы. Kortex обходится без него:
он читает нулевой слой прошивки и сопоставляет каждую физическую клавишу схемы с ячейкой матрицы,
у которой тот же код QMK. Выученная матрица запоминается для этого устройства — иначе после правки
клавиш совпадение по кодам перестало бы работать. Кнопка «Пересопоставить» повторяет разбор
по заводской раскладке.

## Что покрыто из VIA и Vial

| Возможность VIA | Kortex |
|---|---|
| Правка раскладки и слоёв в прошивке | да |
| Тестер клавиш | да, шире: дребезг, NKRO, тепловая карта, журнал событий |
| Динамические макросы в памяти платы | да, запись и чтение |
| Подсветка: яркость, эффект, скорость, цвет | да, RGB-подсветка и бэклайт |
| Сохранение и загрузка раскладки в файл | да, формат файлов VIA |
| Сброс раскладки к заводской | да |
| Сброс памяти платы (EEPROM) | да |
| Перевод в режим прошивки | да |
| Варианты раскладки (layout options) | значение читается и пишется; отдельного экрана нет — сборка платы выбирается своими переключателями |
| Энкодеры | команды протокола реализованы; экрана нет, потому что число энкодеров без файла описания платы не узнать |
| Пользовательские меню VIA 3 | нет: описываются файлом определения платы, которого у Kortex нет |

| Возможность Vial | Kortex |
|---|---|
| Обнаружение платы с Vial | да, отмечается в разделе «Устройство» |
| Тест матрицы | да, через низкоуровневый хук Windows |
| Tap dance, комбо, key overrides, настройки QMK | нет: требуют распаковки сжатого описания платы из прошивки |
| Разблокировка (unlock) | нет |

Платы KBDfans, включая KBD8X MKIII, поставляются с прошивкой VIA — для них Kortex закрывает
весь рабочий цикл. Возможности из второй таблицы имеют смысл только для плат, специально
перепрошитых под Vial.

## Ограничения, о которых стоит знать

- Правка прошивки требует ответа платы по VIA. Kortex реализует команды `0x01`–`0x15`
  и каналы подсветки; расширения Vial не поддерживаются.
- Кодирование макросов и адресация подсветки следуют соглашениям VIA, но проверялись на программной
  модели платы, а не на железе: при первом запуске на реальной плате стоит убедиться,
  что записанный макрос отрабатывает ожидаемо.
- Раздел «Переназначение» работает только пока программа запущена: это слой Windows, а не прошивка.
- Клавиша Fn обрабатывается контроллером платы и до Windows не доходит — в тесте она неактивна.
- Размер матрицы для незнакомых плат берётся по форм-фактору; если сопоставилось меньше клавиш,
  чем ожидалось, это видно в счётчике `MATRIX n / m` на экране раскладки.

## Сборка и запуск

```bash
dotnet build Kortex/Kortex.csproj -c Release
dotnet run --project Kortex/Kortex.csproj
```

Нужен .NET 9 SDK для Windows. Решение `Kortex.sln` открывается в Visual Studio 2022.
Настройки хранятся в `%AppData%\Kortex\profiles.json`.

Переменная окружения `KBS_TRACE=1` включает лог ошибок привязок WPF в
`%Temp%\keyboardstudio-trace.log` — полезно при доработке интерфейса.

`KORTEX_PORTFOLIO=1` запускает сборщик материалов для портфолио: приложение переключается
на английский, наполняется демонстрационными данными, снимает все экраны в двойном разрешении
и собирает обложку, лист возможностей, палитру и логотип в папку `portfolio`. После правок
интерфейса достаточно запустить приложение с этой переменной, чтобы обновить весь набор.

## Структура

```
Hid/            перечисление HID-устройств и обмен сырыми отчётами
Via/            протокол VIA, коды QMK, транспорт и программная модель платы
Devices/        каталог моделей, поиск и подключение клавиатур
Input/          низкоуровневый хук, отправка событий, таблица VK-кодов
Interop/        P/Invoke: хук, SendInput, оформление окна
Models/         раскладка платы, профили, правила, макросы
Services/       движок переназначений, запись макросов, хранение профилей
Localization/   словарь интерфейса и разметочное расширение {loc:Tr}
ViewModels/     модели представления и конвертеры
Views/          схема платы и экраны приложения
Theme/          палитра, стили элементов, анимации
```
